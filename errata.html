整体截面函子的方向写反

原文把 Γ : Sch → Ring 称为协变函子。对概形态射 f : X → Y，整体截面诱导环同态 Γ(Y,OY) → Γ(X,OX)，因此应写成 Γ : Schop → CRing，或等价地 Sch → CRingop。

高阶 Tor 消失的理由表述过宽

光滑曲面或正则局部环本身并不保证任意两个子概形的所有高阶 Tor 都消失。对无公共分支的平面 Cartier 除子，可由定义方程在另一商环中为非零因子推出相关的 Tor1 消失；这里应补充对象与相交条件。

二重点与二重直线混淆

Spec K[x]/(x²) 的底空间只有一个点，是带幂零结构的二重点。若要描述支撑在一条直线上的二重结构，可以使用 Spec K[x,y]/(x²)，其约化支撑为 A¹。
